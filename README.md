# DevStories Blog

A responsive editorial-style blog inspired by modern reading platforms. Built with semantic HTML, CSS, and vanilla JavaScript.

## Features
- Responsive homepage with a hero banner and six article cards
- Topic filters for Development, Design, Technology, and Career
- Individual article page with six article variations
- Mobile navigation menu with accessible state labels
- Google Fonts, author avatars, image thumbnails, hover effects, and keyboard skip links

## Run locally
1. Open this folder in Visual Studio Code.
2. Open `index.html` with Live Server, or open it directly in a browser.
3. Click a story card to open its article page.
4. Use the topic buttons to filter stories.

Images and fonts are loaded from online services, so an internet connection is needed for those assets.

## Suggested learning and Git workflow
Build and commit features in small steps. Example commit messages:
1. Create project structure and README
2. Add semantic homepage structure
3. Add header and navigation
4. Create hero banner
5. Add featured story section
6. Add six article cards
7. Style typography and color palette
8. Add responsive tablet layout
9. Add mobile navigation
10. Add category filters
11. Create article page layout
12. Add article content switching
13. Improve accessibility and final spacing


## Technologies Used

- **HTML5:** Semantic page structure and accessible navigation.
- **CSS3:** Responsive layouts, typography, colors, and hover effects.
- **Vanilla JavaScript:** Topic filtering, mobile menu interactions, and article content switching.
